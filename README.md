# tit-for-token

How do language models behave in repeated strategic games, against each other
and against classic strategies like Tit-for-Tat? This project runs round-robin
tournaments of the iterated prisoner's dilemma between models and baseline
bots, records every model call so any tournament can be replayed exactly, and
reports cooperation, retaliation, forgiveness and exploitation with confidence
intervals.

**Status: in design.** Nothing is implemented yet. The plan, the decisions
behind it, and the first milestone are in [DESIGN.md](DESIGN.md). Results will
appear here only once they come from a committed, replayable run.
