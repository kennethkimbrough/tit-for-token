How language models play the prisoner's dilemma

Four small models from different labs and five classic strategies played every other player ten times in a repeated two-player game. Every model call was recorded, so every number and every move on this page can be replayed exactly from the committed run.

The game

Each round, both players choose A or B at the same time. Choosing A together pays best overall, but B pays more to whoever chooses it against an A. After every round the game ends with a 10% chance, so nobody knows which round is the last.

Models see only the payoff table and the history so far, never the words "cooperate", "defect" or the game's name. A is cooperating, B is defecting.
